# Responsive Multi-Page Landing Website

This is my **first real web development project**, built as part of my journey into frontend development.

It is a responsive, multi-page website for a fictional cybersecurity company called **CyberSecure**, featuring:

🚀 Features
- Multi-page navigation: Home, Services, About, Contact, Login
- Responsive design (mobile & desktop friendly)
- Contact form with **localStorage saving**
- Login form storing user email
- Clean and modern UI with Flexbox

🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- Flexbox layout
